Linear Regression

Linear Regression is to represent relationship among 2 or more variables.This blog will show how to calculate the coefficients by the method the Least Mean Square(LMS).

One-dimension linear Regression

For a subset data (x,y), we want to find a line ($\hat{y} = \beta_0+\beta_1*x$)which can meet the relationship between y and x as much as possible.

Assume the Fitting linear equation is as follow,

$$
\hat{y} = {\beta_0}+{\beta_1}x \tag{1}
$$

The difference(Error) is ${e}$ which can be express as,
$$
{e}=y-\hat{y} = y-{\beta_0}-{\beta_1}x\tag{2}
$$
In gernal ，the error’s value is our consideration and ignore the sign,so we will take error’s square or absolute value as indicator.In the blog ,take ${e}^2$ as error’s indicator.We can calculate the${\beta_0},{\beta_1}$ by finding the extreme value,which case the error is the least value.

$$ \begin{gather*} \frac{\partial{{e}^2}}{\partial{{\beta_0}}}=\frac{\partial{(y-{\beta_0}-{\beta_1x})^2}}{\partial{{\beta_0}}}=-2(y-{\beta_0}-{\beta_1}x)\tag{3}\\ \frac{\partial{{e}^2}}{\partial{{\beta_1}}}=\frac{\partial{(y-{\beta_0}-{\beta_1x})^2}}{\partial{{\beta_1}}}=-2(y-{\beta_0}-{\beta_1}x)x\tag{4} \end{gather*} $$

For multiple samples,we need to add the error and find the least value.

$$ \begin{align} \frac{\partial{\Sigma{e_i}^2}}{\partial{{\beta_0}}}=\frac{\partial{\Sigma(y_i-{\beta_0}-{\beta_1}x_i)^2}}{\partial{{\beta_0}}}=-2\Sigma( y_i-{\beta_0}-{\beta_1}x_i)\tag{5} \\ \frac{\partial{\Sigma{e_i}^2}}{\partial{{\beta_1}}}=\frac{\partial{\Sigma(y_i-{\beta_0}-{\beta_1}x_i)^2}}{\partial{{\beta_1}}}=-2\Sigma(y_i-{\beta_0}-{\beta_1}x_i)x_i\tag{6} \end{align} $$

To find the error least, we need make the equation(5),(6) equls to 0.

$$ \begin{gather*} -2\sum_{i=1}^n(y_i-{\beta}_0-{\beta}_1x_i)=0\\ \Downarrow\\ n{\beta}_0=\sum_{i=1}^n(y_i-{\beta}_1x_i)\\ \Downarrow\\ {\beta}_0=\bar{y}-{\beta}_1\bar{x}\tag{7} \end{gather*} $$ Substitue $\beta_0$ in equation (7) to (6), $$ \begin{gather*} -2\sum_{i=1}^{n}(y_i-{\beta}_0-{\beta}_1x_i)x_i=0\\ \Downarrow\\ \sum_{i=1}^n(y_i-(\bar{y}-{\beta}_1\bar{x})-{\beta}_1x_i)x_i=0\\ \Downarrow\\ \sum_{i=1}^n(x_iy_i-x_i\bar{y}+{\beta}_1x_i\bar{x}-{\beta}_1x_i^2)=0\\ \Downarrow\\ {\beta}_1\sum_{i=1}^n(x_i\bar{x}-x_i^2)=\sum_{i=1}^n(\bar{y}x_i-x_iy_i)\\ \Downarrow\\ {\beta}_1=\frac{\sum x_iy_i-\bar{y}\sum x_i}{\sum x_i^2-\bar{x}\sum x_i}=\frac{\sum(y_i-\bar{y})(x_i-\bar{x})}{\sum(x_i- \bar{x})^2}\tag{8} \end{gather*} $$

So we solved one dimension linear regression.And Next we will spread the method to multiple dimension by Array calculation

Multiple Dimension linear regression

For multiple dimension subset$(x_{1i},x_{2i},…,x_{ni},y_i)$，the linear regression relationship can be as follow,

$$ \hat{y}_i={\beta}_0+{\beta}_1x_{i1}+{\beta}_2x_{i2}+...+{\beta}_nx_{in}=\boldsymbol{{\beta}^T}\cdot \boldsymbol{x_i}\tag{9}=\boldsymbol{{x_i}^T}\cdot\boldsymbol{\beta} $$

In the equation,$\boldsymbol{{\beta}^T}=[{\beta}_0,{\beta}_1,...,{\beta}_n]$,$\boldsymbol{{x_i}^T}=[1,x_{i1},x_{i2},...,x_{in}]$ .
For multiple groups variables , the linear regression can be expressed as,

$$ \begin{gather*} \left[ \begin{array}{c} \hat{y}_1\\ \hat{y}_2\\ \vdots\\ \hat{y}_m \end{array} \right] = \begin{bmatrix} 1&x_{11}& x_{12}&\cdots&x_{1n}\\ 1&x_{21}&x_{22}&\cdots&x_{2n}\\ \vdots&\vdots&\vdots&\ddots&\vdots\\ 1&x_{m1}&x_{m2}&\cdots&x_{mn} \end{bmatrix} \cdot \left[ \begin{array}{c} {\beta}_0\\ {\beta}_1\\ \vdots\\ {\beta}_n \end{array} \right] \end{gather*} $$

Simplify the expression as

$$ \boldsymbol{\hat{y}}=\boldsymbol{X}\cdot\boldsymbol{\beta}\tag{10} $$

The error can $e^2$ be express as follow,

$$ \begin{gather*} \begin{aligned} e^2&=(\boldsymbol{y}-\boldsymbol{\hat{y}})^T\cdot(\boldsymbol{y}-\boldsymbol{\hat{y}})\\ &=(\boldsymbol{y}-\boldsymbol{X}\cdot\boldsymbol{\beta})^T\cdot(\boldsymbol{y}-\boldsymbol{X}\cdot\boldsymbol{\beta})\\ &=\boldsymbol{y}^T\cdot\boldsymbol{y}-\boldsymbol{\beta}^T\boldsymbol{X}^T\boldsymbol{y}-\boldsymbol{y}^T\boldsymbol{X}\boldsymbol{\beta}+\boldsymbol{\beta^TX^TX\beta} \end{aligned}\\ \Downarrow\\ \begin{aligned} \frac{\partial{e^2}}{\partial\boldsymbol{\beta}}=-\boldsymbol{y^TX}-\boldsymbol{y^TX}+\boldsymbol{\beta^TX^TX}+\boldsymbol{\beta^TX^TX}=0\\ \end{aligned}\\ \Downarrow\\ \boldsymbol{\beta^TX^TX}=\boldsymbol{y^TX}\\ \Downarrow\\ \boldsymbol{X^TX\beta}=\boldsymbol{X^Ty}\\ \Downarrow\\ \boldsymbol{\beta}=\boldsymbol{{(X^TX)}^{-1}X^Ty}\tag{11} \end{gather*} $$

Git and Github

Posted on 2025-03-15

Git 有多种命令

Git 有远程仓库和本地仓库两种。各个仓库中的内容又有多个分支，主要包括主分支（main）和其他分支。
每个人可以把远程分支拷贝到本地，进行本地修改，最后把本地仓库在上传到远程仓库中。

git clone address

将远程仓库复制到本地。

git commit -m “comment”

提交到版本控制

git branch

  • git branch -vv
    查看本地分支和远程分支的对应关系
  • git branch -a
    查看本地和远程所有的分支
  • git branch –set-upstram-to-origin/xxx
    将本地分支上传到远程仓库的xxx分支并形成关联
  • git branch -d xxx
    删除本地分支
    ps:不能删除当前分支
  • git push origin –delete xxx
    删除远程分支（慎用）。

git checkout

  • git checkout -b xxx
    以当前分支为基础新建一个xxx分支
  • git checkout xxx
    从当前分支切换到 xxx分支
  • git checkout .
    恢复到 git add .之前的内容。

git push

  • git push origin xxx
    将本地分支更新到远程分支
    ps:这与 git branch –set-upstream-to-origin/xxx 区别是 能不能形成关联

git status

查看本地git的状态
查看仓库的变化

git add .

添加到缓存里面

git pull

从远程拉取最新代码。
多人协同编写代码时，使用git pull来看当前的最新代码。

git merge xxxx

把两个分支的代码合并一下。
两个分支同时修改，导致merge出现冲突。
将 xxxx 分支插入到当前分支。
xxxx内的分支内容不改变，而当前分支内容会被改动。
note: git merge 容易出问题，慎用。

git diff

查看修改的文件

git reset

缓存区内容回退
  • git reset –mixed
    缓存区所有内容回退
    本地内容修改，但是缓存区内容恢复到上一次。
  • git reset HEAD .
    同样是回退缓存区内容。
  • git reset HEAD filename
    指定文件 不添加到缓存。
  • git reset –soft HEAD^
    commit之后文件 回退的暂存区。
  • git reset –hard HEAD^
    commit / add 两步同时回退。

git stash

贮藏功能

  • git stash save xxx
    将写好的内容暂时贮藏，不提交。
  • git stash list
    查看贮藏列表
  • git stash pop stash@{1}
    查看列表后，根据编号把内容提出出来

git config

  • git config –list
    查看配置信息

git log

  • git log –graph –oneline
    使用简要图示显示git的信息。
    通过编号可以回退到需要的版本。
    使用 git reset –hard code

单边周期信号Laplance变换

$$
\begin{aligned}
x(t)&\stackrel{L}{\longrightarrow}X(s),& x \in R \\
x(t-T)&\stackrel{L}{\longrightarrow}X(s)\cdot e^{-sT},&x\in R \\
x(t-2T)&\stackrel{L}{\longrightarrow}X(s)\cdot e^{-s2T},&x\in R\\
\vdots \\
x(t-nT)&\stackrel{L}{\longrightarrow}X(s)\cdot e^{-snT},&x\in R
\end{aligned}
$$
若$x_T(t)=\sum\limits_{n=0}^{+\infty}x(t-nT)$
则
$$
\begin{aligned}
x_T(t)&\stackrel{L}{\longrightarrow}\lim_{n\to+\infty}(1+e^{-sT}+e^{-2sT}\cdots+e^{-nsT})X(s) \\
&=\lim_{n\to+\infty}\frac{1-e^{-(n+1)sT}}{1-e^{-sT}}X(s)
\\
&\overset{Re[s]>0}{=}\frac{1}{1-e^{-sT}}X(s),&R\cap Re[s]>0
\end{aligned}
$$

例题

1.
$$
\lim\limits_{n=0}^{+\infty}\delta(t-nT)\stackrel{L}{\longrightarrow}\frac{1}{1-e^{-sT}},Re[s]>0
$$
2.
原始单边laplace变换
$$
\begin{aligned}
x(t)&=u(t)-u(t-T/2)\\
x(t)&\stackrel{L}{\longrightarrow} \frac{1-e^{-sT/2}}{s}
\end{aligned}
$$
对于周期性波形来说
$$
x_T(t)\stackrel{L}{\longrightarrow} \frac{1-e^{-sT/2}}{s}\cdot\frac{1}{1-e^{-sT}},Re[s]>0
$$

  • 题型一

    $$
    y’’+3y’+2y=x
    $$

    当$ x(t)=e^{-t}u(t)$时，求y(t)

    • 解

    $$
    H(s)=\frac{1}{s^2+3s+2}
    $$

$$
\begin{aligned}
Y(s)&=H(s)\cdot X(s) \\

&=\frac{1}{(s+1)^2}\cdot\frac{1}{s+2} \\
&=\frac{A}{(s+1)^2}+\frac{B}{s+1}+\frac{C}{s+2} \\
&=\frac{1}{(s+1)^2}-\frac{1}{s+1}+\frac{1}{s+2}
\end{aligned}
