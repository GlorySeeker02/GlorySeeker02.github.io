Git 有多种命令

Git 有远程仓库和本地仓库两种。各个仓库中的内容又有多个分支，主要包括主分支（main）和其他分支。
每个人可以把远程分支拷贝到本地，进行本地修改，最后把本地仓库在上传到远程仓库中。

git clone address

将远程仓库复制到本地。

git commit -m “comment”

提交到版本控制

git branch

  • git branch -vv
    查看本地分支和远程分支的对应关系
  • git branch -a
    查看本地和远程所有的分支
  • git branch –set-upstram-to-origin/xxx
    将本地分支上传到远程仓库的xxx分支并形成关联
  • git branch -d xxx
    删除本地分支
    ps:不能删除当前分支
  • git push origin –delete xxx
    删除远程分支（慎用）。

git checkout

  • git checkout -b xxx
    以当前分支为基础新建一个xxx分支
  • git checkout xxx
    从当前分支切换到 xxx分支
  • git checkout .
    恢复到 git add .之前的内容。

git push

  • git push origin xxx
    将本地分支更新到远程分支
    ps:这与 git branch –set-upstream-to-origin/xxx 区别是 能不能形成关联

git status

查看本地git的状态
查看仓库的变化

git add .

添加到缓存里面

git pull

从远程拉取最新代码。
多人协同编写代码时，使用git pull来看当前的最新代码。

git merge xxxx

把两个分支的代码合并一下。
两个分支同时修改，导致merge出现冲突。
将 xxxx 分支插入到当前分支。
xxxx内的分支内容不改变，而当前分支内容会被改动。
note: git merge 容易出问题，慎用。

git diff

查看修改的文件

git reset

缓存区内容回退
  • git reset –mixed
    缓存区所有内容回退
    本地内容修改，但是缓存区内容恢复到上一次。
  • git reset HEAD .
    同样是回退缓存区内容。
  • git reset HEAD filename
    指定文件 不添加到缓存。
  • git reset –soft HEAD^
    commit之后文件 回退的暂存区。
  • git reset –hard HEAD^
    commit / add 两步同时回退。

git stash

贮藏功能

  • git stash save xxx
    将写好的内容暂时贮藏，不提交。
  • git stash list
    查看贮藏列表
  • git stash pop stash@{1}
    查看列表后，根据编号把内容提出出来

git config

  • git config –list
    查看配置信息

git log

  • git log –graph –oneline
    使用简要图示显示git的信息。
    通过编号可以回退到需要的版本。
    使用 git reset –hard code
